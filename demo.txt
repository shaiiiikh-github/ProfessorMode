TEST CASE 3: Operating Systems — Deadlock Detection & Characterization
================================================================================
Question:
What is a deadlock in operating systems?

Reference Answer:
Deadlock is a situation where a set of processes are blocked because each process is holding a resource and waiting for another resource acquired by some other process in the set, leading to a circular wait condition.

Student Answer:
Deadlock occurs when two or more processes are permanently stuck waiting for resources held by each other, causing a circular waiting chain where none of them can proceed.

Expected Quality Result:
- Final Score: ~85 - 90 / 100 (Grade: A)
- Key Covered: processes, resources, circular wait, blocked execution.

================================================================================
Question:
Describe the Model-View-Controller (MVC) architecture.

Reference Answer:
MVC is a software architectural pattern consisting of three parts: Model (manages data and business logic), View (handles UI display), and Controller (acts as an interface between Model and View).

Student Answer:
MVC separates an application into three distinct layers: the Model layer which encapsulates data and business logic, the View which handles visual UI rendering, and the Controller that routes user requests and coordinates updates between Model and View.
